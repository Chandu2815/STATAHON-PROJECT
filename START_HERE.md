## 🔧 TROUBLESHOOTING:

### ❌ Port 8000 already in use?
```bash
kill -9 $(lsof -ti :8000)
./start.sh
```

### ❌ Python 3.13 not found?
```bash
python3 -m uvicorn main:app --host 127.0.0.1 --port 8000
```

### ❌ Dependencies missing?
```bash
pip install -r requirements.txt
./start.sh
```
